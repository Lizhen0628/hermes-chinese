# 会话心跳（`/heartbeat`）

`/heartbeat` 为**当前会话**提供一条周期性指令。每当会话空闲且时间间隔已过，该提示就会作为普通用户轮次触发——同样的对话、同样的上下文、同样的提示缓存。

```
/heartbeat every 10m Check the deployment and report meaningful changes
```

灵感来自 Prime-Agent 的 `/heartbeat`。Hermes 的适配版本保留了严格的消息流不变式：心跳只在轮次之间注入（绝不在运行中途），并作为一条普通的 user 角色消息。

## 心跳 vs 定时任务：我该用哪个？

它们看起来相似，但服务于不同的用途：

| | `/heartbeat` | [`hermes cron`](./cron) |
|---|---|---|
| 运行于 | **本对话**——完整上下文、对讨论的记忆 | 每个滴答一个全新的隔离会话 |
| 能否在进程重启后存活 | 状态可存活（SessionDB）；网关监视线程会在重启后自动恢复 | 可以——完全持久的调度器 |
| 数量 | 每个会话一个 | 不限数量的任务 |
| 最适合 | "在我们工作*这个线程*时，盯着 X" | 常驻任务、报告、看门狗、投递 |

经验法则：如果周期性提示需要对话的上下文，用 `/heartbeat`。如果是一个自包含的任务，用定时任务。

## 命令

| 命令 | 作用 |
|---|---|
| `/heartbeat every <interval> <prompt>` | 设置（或替换）会话的心跳。间隔：`90s`、`10m`、`2h`、`1d`（最小 60s）。 |
| `/heartbeat` 或 `/heartbeat status` | 显示心跳、其间隔以及距下次触发的时间。 |
| `/heartbeat pause` | 停止触发但不清除。 |
| `/heartbeat resume` | 恢复（重新锚定计时器——不会立即触发陈旧的心跳）。 |
| `/heartbeat clear` | 移除心跳。 |

`/hb` 是别名。可在 CLI、TUI / Desktop 应用以及网关平台上使用（在 Slack 上，请使用 `/hermes heartbeat …`）。

## 行为细节

- **仅在空闲时。** 心跳绝不会打断正在进行的轮次。如果到滴答时间时智能体正忙，它会在下一次空闲轮询时触发。在网关中，一个空闲的被监视会话会主动唤醒；无需新的入站消息。
- **错过的滴答会合并。** 如果会话在多个间隔内一直忙碌（或进程未运行），你只会得到一个心跳轮次，而不是积压的一堆。计时器每次触发都会重新锚定。
- **用户消息优先。** 排队的用户消息始终优先；心跳会等待输入队列排空。
- **缓存安全。** 注入的提示是一条普通用户消息。不修改系统提示，不更改工具集。
- **网关恢复。** 启动时会使用当前持久化的对话和线程路由，在所属配置档中恢复活跃心跳。每次轮询都会在临时存储故障或适配器停机后重试恢复；已暂停和已清除的心跳以及已挂起的对话不会重启。无需新的聊天消息。
- **持久性与对话边界。** 状态存放在 `SessionDB.state_meta` 中，以 `heartbeat:<session_id>` 为键，并跟随上下文压缩导致的会话轮换。在消息网关中，通过重置、切换或挂起离开对话会清除其心跳；恢复该已归档的对话不会使其复活。触发需要所属进程（CLI 会话或网关）正在运行。已经准入的网关滴答会在会话解析之后、智能体执行之前再次检查：它可以跟随压缩后的子会话，但不能将其旧指令带入重置或切换后的对话。
- **执行核算。** 网关在适配器准入时预留一个到期的滴答。如果该确切尝试在进入智能体运行器之前结束（包括取消，或路由、授权、紧急停止或准备阶段的拒绝），它会退还该滴答，除非此后调度已变更。一旦进入智能体运行器，即使执行失败或被中断，该次触发仍被计入。此计数**并非**模型响应成功或出站投递成功的证明；进程突然死亡可能会阻止退还回调。
- **不无中生有守卫。** 注入的提示会告知智能体在无实质变化时简短答复并停止，因此空闲的心跳不会产生无谓的工作。

## 示例

```
你: /heartbeat every 15m Check whether the CI run for PR #1234 finished; summarize the result when it does

  ♥ Heartbeat set (every 15m): Check whether the CI run for PR #1234 finished; ...

[15 分钟里你在同一会话中处理其他事情]

Hermes: [心跳——周期性指令，每 15m 触发一次]
  💻 gh pr checks 1234   (1.2s)
  CI is still running (14/37 checks complete). Nothing to report yet.
```

当答案不再变化时，用 `/heartbeat clear` 清除它——或者让它继续守望。
