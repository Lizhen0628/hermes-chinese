# CLI 符号术语表

Hermes 终端界面使用一套简洁的视觉语言：圆点、尖角号、盲文旋转指示器和状态字形。本页是解码环。它涵盖了 [TUI](../user-guide/tui.md)（这些符号大多在此呈现），并说明了与 [Classic CLI](../user-guide/cli.md) 共享的部分。

:::note 皮肤可以重新设计其中一些符号的样式
下面标记为*可主题化*的字形为品牌默认值 —— [皮肤](../user-guide/features/skins.md)可以覆盖它们（例如 `tool_prefix` 和提示符）。其他所有字形在渲染器中都是固定的。
:::

## 会话流符号

智能体工作时你在对话流中看到的内容。

| 符号 | 含义 |
|--------|---------|
| `❯` | 输入提示符 —— 你输入内容的位置。*可主题化*（皮肤可以设置各自的提示符）。 |
| `●` | 一次工具调用。这个项目符号位于工具名称及其参数之前。 |
| `┊` | 工具行中显示的工具活动轨。*可主题化*（`tool_prefix`）。 |
| `✓` / `✗` | 工具结果：成功 / 失败。追加在已完成的工具行末尾。 |
| `▸` / `▾` | 折叠 / 展开部分的尖角号（思考、工具、子智能体、横幅各区块）。点击可切换。 |
| `▍` | 流式输出光标 —— 在模型仍在输出文本时闪烁。 |
| `│` `├─` `└─` | 树形导轨 —— 将父项（一次委派、一段旅程）与其子条目连接起来；`└─` 标记最后一个子项。 |
| `◈` | 仅显示的时间线事件（内联呈现的会话通知，而非用户消息）。 |
| `◇` | 一个注入的引用块，例如 `◇ Reference 1/2 — <label>`。 |
| `↳` | 固定提示符 —— 回显智能体当前正在处理的用户消息。 |
| `☐` / `☑` / `•` | Markdown 任务列表项（未完成 / 已完成）和普通列表项目符号。 |
| `▶` | 渲染后的 markdown 中折叠的 `<details>` 摘要。 |

## 状态栏符号

TUI 底部的那一行。各分段仅在相关时出现，在窄终端上会最先消失。

| 符号 | 含义 |
|--------|---------|
| `⠋⠙⠹…`（盲文图案） | 忙碌旋转指示器。思考阶段和工具阶段使用不同的盲文动画集。 |
| `☤ 🌀 🤔 ✨ 🍵 🔮` | `emoji` 忙碌指示器风格的各帧（`/indicator emoji`）。默认风格则轮换颜文字表情。 |
| <code>&#124; / - &#92;</code> | `ascii` 忙碌指示器风格的各帧。 |
| `⏱` | 轮次运行期间每个提示符的已用时间，例如 `⏱ 12s/3m 45s`（轮次时间 / 会话时间）。 |
| `⏲` | 同一个计时器，在轮次完成后冻结。 |
| `cmp N` | 当前会话已被自动压缩 N 次。 |
| `▶ N` | 当前正在运行的 N 个 `/bg` 任务。 |
| `⚠ YOLO` | YOLO 模式已开启（自动审批）。也会显示在启动横幅中。 |
| `⛓ N` | 当前活跃的 N 个子智能体。 |
| `↩ resumes when subagent finishes` | 当你处于空闲但委派的工作仍在进行中时显示的安抚提示 —— 结果会自行返回。 |
| `● REC` | 语音模式正在录音。 |
| `◉ STT` | 语音录音已停止；语音转文字正在转录。 |
| `◉ focus` | 专注视图已开启（精简输出）。被固定，因此在窄终端上也不会消失。 |
| `♥` | 情感闪烁 —— Hermes 注意到你在友善对待它。 |
| `⚡` / `🔋` | 电池指示器（选择启用）：已接通电源 / 使用电池，带百分比。 |
| `N bg` | 此会话中追踪的 N 个后台终端进程。 |
| `N live sessions` | 此进程中打开的 TUI 会话 —— 点击可打开会话切换器。 |

## 通知

短暂的状态栏通知带有各自的领头字形，由严重级别决定：

| 符号 | 含义 |
|--------|---------|
| `✓` | 成功通知。 |
| `•` | 信息通知。 |
| `⚠` | 警告（也用于额度警告）。 |
| `✕` | 错误通知。 |

## 审批与确认提示

| 符号 | 含义 |
|--------|---------|
| `⚠ approval required` | 某个工具想要运行需要你明确同意方可执行的操作（带命令预览的边框面板）。 |
| `⚠` / `?` | 确认对话框标题：危险操作 / 普通询问。 |
| `🔐` | Sudo 密码提示（输入被遮蔽）。 |
| `🔑` | 凭据/密文输入提示（输入被遮蔽）。 |

## 子智能体浮层（`/agents`）

| 符号 | 含义 |
|--------|---------|
| `●` | 子智能体正在运行。 |
| `○` | 已排队。 |
| `✓` | 已完成。 |
| `■` | 已中断。 |
| `✗` | 已失败。 |
| `⌛` | 已超时。 |
| `⚠` | 出错。 |
| `⚡N` | 汇总行中当前活跃的 N 个智能体。 |
| `▁▂▃▄▅▆▇█` | 活动迷你折线图 —— 每个分支最近的事件量。 |

## 会话切换器（`Ctrl+X`）

| 符号 | 含义 |
|--------|---------|
| `✓` | 会话空闲。 |
| `…` | 正在启动。 |
| `?` | 正在等待输入。 |
| `▶` | 正在工作。 |
| `✎ draft` | 该会话的编辑器中有一份未发送的草稿。 |

## 选择器与中心

| 符号 | 含义 |
|--------|---------|
| `▸` | 当前选中行（模型选择器及类似界面）。 |
| `*` | 当前活跃的模型 / 服务商。 |
| `●` / `○` | 服务商已认证 / 未认证（模型选择器）；插件状态回退（插件中心）。 |
| `✓` / `✗` | 插件已启用 / 已禁用（插件中心）。 |
| `↑ N more` / `↓ N more` | 列表可见窗口上方/下方还有更多行。 |
| `┃` | 可滚动浮层上的滚动条滑块。 |

## 目标

目标生命周期通知（来自[目标](../user-guide/features/goals.md)）以其状态字形开头：

| 符号 | 含义 |
|--------|---------|
| `✓` | 目标已完成。 |
| `↻` | 目标继续进行 —— 已安排另一次迭代。 |
| `⏸` | 目标已暂停。 |
