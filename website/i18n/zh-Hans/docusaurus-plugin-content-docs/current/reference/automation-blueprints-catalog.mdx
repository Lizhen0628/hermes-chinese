# 自动化蓝图

自动化蓝图是开箱即用的自动化流程。挑选一个，填写几个字段，Hermes 便会将其调度为定时任务——无需了解 cron 语法。

每个蓝图都支持 **所有入口**：

- **仪表盘 / 桌面应用** — 打开 Cron 页面，切换到 **Blueprints** 选项卡，填写表单，然后点击 *Schedule it*。
- **CLI、TUI 和消息应用** — 输入 `/blueprint <name>`（例如 `/blueprint morning-brief`），Hermes 会逐条询问它所需的信息，然后进行调度。名称匹配是宽松的——前缀或近似拼写都能解析。高级用户可以通过内联传值跳过问答： `/blueprint morning-brief time=08:00`。
- **桌面应用** — 在任意蓝图上点击 **Send to App**，它会在你的输入框中预加载命令并打开。

蓝图绝不会静默调度任何内容——任务创建之前你始终需要确认。随时可以用 `/cron` 管理已创建的任务。

## 编写你自己的蓝图

蓝图其实就是一个技能，只需在其 `SKILL.md` 前置元数据中包含一个 `metadata.hermes.blueprint` 块。有关槽位 schema 以及如何发布，请参阅
[创建技能 → 自动化蓝图](../developer-guide/creating-skills.md)。
